# Almas Projekt — Cloudflare-сыз іске қосу

Бұл нұсқада бұрынғы тіркелу беті, шағын пернетақта, `.almasinvite` файлы және стадионды көру беті бар. Telegram боты мен тіркелу API-і бір Node.js процесінде, деректер SQLite базасында жұмыс істейді. Қосымша npm пакеттерін орнату қажет емес. Кейіпкермен жүру және көп ойыншы режимі әлі іске асырылмаған.

## Windows-та қосу

1. Node.js **24 немесе одан жаңа** нұсқасы қажет. Сенде көрсетілген 24.19.0 жарайды.
2. ZIP-ті толық шығар. Бұрын толтырған `BOT_CONFIG_LOCAL.txt` файлың `Downloads` ішінде немесе `START_ALMAS.cmd` жанында тұрсын. Токенді чатқа жіберу не қайта енгізу қажет емес.
3. `START_ALMAS.cmd` файлын аш. Ноутбуктің браузері автоматты ашылады. Телефонға арналған нақты мекенжай CMD терезесінде көрсетіледі. Екі құрылғы бір Wi-Fi желісінде болуы керек; Windows Firewall сұраса, жеке желіге рұқсат бер.
4. Telegram-да өз ботыңның **жеке чатына** `/new Almas_01` деп жаз. `ADMIN_TELEGRAM_ID` сәйкес келген әкімші ғана шақыру жасай алады.
5. Бот жіберген `.almasinvite` файлын ойыншыға бер. Ойыншы сайтқа жүктеп, пароль орнатады да, стадионға кіреді.

Браузерде парольмен кіру қолжетімді. Телефон құлпы бұрынғы Android қолданбасындағы native bridge арқылы ғана жұмыс істейді. APK әлі GitHub Pages мекенжайын ашады; бұл локал нұсқаны телефонның браузерімен аш. APK-ны жаңа серверге бағыттау үшін нақты тұрақты HTTPS мекенжай қажет.

Терезе ашық және ноутбук қосулы тұрғанда ғана сервер жұмыс істейді. `Ctrl+C` тоқтатады. Стадион сыртқы Sketchfab бетінен жүктелетіндіктен интернет керек.

### Егер ботта webhook бұрын орнатылған болса

Сервер оны өздігінен өшірмейді. CMD-де осы бумаға кіріп:

```bat
START_ALMAS.cmd --take-over-webhook
```

Бұл ботты жаңа серверге ауыстырады; кезектегі Telegram хабарламаларын өшірмейді. Бір бот үшін бір сервер процесін ғана қос. Қате токен не басқа процесс анықталса, бот тоқтағанын хабарлайды; жұмыс істеп тұрған аккаунттардың API-і сақталады.

## Деректерді сақтау

- Windows: `%LOCALAPPDATA%\AlmasProjekt\server\almas.sqlite`
- Linux: `~/.local/share/almas-projekt/almas.sqlite`
- Басқа бума: `ALMAS_DATA_DIR` айнымалысын немесе конфигурациядағы осы жолды қолдан.

Аккаунттар, шақырулар, Telegram offset және шифрлау кілттері осы базада сақталады. Серверді жаңарту оларды ауыстырмайды. Базаны көшіру/резервтік көшірме жасау алдында серверді тоқтат; каталогты түгел көшір. Көшірме құпия дерек болып саналады.

Cloudflare D1-ден деректер автоматты көшірілмейді. Ол жақта бұрын берілген шақырулар болса, олар жаңа базаға сәйкес келмейді. Бұл серверден жаңа шақыру ал.

HTTP тек сенімді жергілікті желідегі тексеруге арналған. Интернетке ашқанда HTTPS қажет. Браузердің құрылғы байланысы браузер профилінің сақталуына тәуелді: оның деректерін өшірсең, сақталған байланыс жоғалады. Стадион моделі — сыртқы жалпыға қолжетімді viewer; `/api/session` қолданбаның кіруін тексереді, Sketchfab моделін жеке ресурсқа айналдырмайды.

## Басқа серверге орналастыру

Node.js 24+ және тұрақты жазылатын диск бар Windows/Linux серверде осы код өзгеріссіз жұмыс істей алады:

```sh
node server/index.mjs
```

Төмендегіні құпия орта айнымалылары немесе жергілікті конфигурация файлы арқылы бер:

```text
TELEGRAM_BOT_TOKEN=
ADMIN_TELEGRAM_ID=
ALMAS_DATA_DIR=/var/lib/almas-projekt
ALMAS_PUBLIC_URL=https://YOUR_REAL_SERVER_DOMAIN
PORT=8080
```

Домен нақты HTTPS reverse proxy-ге бағытталуы керек. Процесті автоматты қайта іске қосатын қызмет қажет. Диск өшіп қалатын немесе ұйқыға кететін хостинг үздіксіз бот пен сақталатын аккаунттарға сәйкес келмейді. Сервер қызметін сатып алу/жариялау бұл өзгерісте орындалмаған.

GitHub Pages-тағы бұрынғы сайтты осы API-ге жалғағанда `ALMAS_APP_ORIGIN=https://jjjjjjjjjjjjjjae-hub.github.io` қосып, нақты HTTPS серверді тексергеннен кейін ғана `app-config.js` ішіндегі `apiBase` мәнін толтыр. Telegram үшін HTTPS webhook керек емес: сервер хабарламаларды өзі `getUpdates` арқылы алады.

Ресми құжаттар: [Telegram getUpdates](https://core.telegram.org/bots/api#getupdates), [Node.js SQLite](https://nodejs.org/docs/latest-v24.x/api/sqlite.html).

## Тексеру

```sh
npm test
```

Тесттер нақты жергілікті SQLite базасын және HTTP API-ін қолданады. Telegram тасымалы тест ішінде алмастырылған; нақты токен қолданылмайды және ешкімге хабарлама жіберілмейді.
